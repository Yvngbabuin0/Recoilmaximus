# Recoilmaximus

Repositorio **público de distribución** de **Rainbow Six — Recoil Pro**, una aplicación de escritorio
para Windows que gestiona perfiles de compensación de retroceso del ratón para *Rainbow Six Siege*.

> En este repositorio solo se publican los **binarios y las notas de versión**.
> El código fuente se mantiene en un repositorio privado.

## Descarga

Ve a la pestaña **[Releases](../../releases/latest)** y descarga el archivo `recoil.exe`.

No requiere instalación: es un único ejecutable portátil.

## Actualizaciones

La aplicación incluye un sistema de actualización automática que consulta la última versión
publicada en este repositorio:

- Comprueba si hay una versión nueva al arrancar (se puede desactivar en **Ajustes**).
- También puedes comprobarlo manualmente desde **Ajustes → Actualizaciones**.
- La descarga se verifica con **SHA-256** antes de instalarse.
- Si estás en partida, el aviso no interrumpe el juego.

## Uso responsable

Esta herramienta está pensada para uso personal y educativo. Úsala bajo tu propia responsabilidad
y respetando las normas de los juegos que utilices.
